# ics55 L3 DCO sparse baseline

This is the first **working transistor-level** ics55 DCO baseline.

## Flow

```sh
python3 flow/characterization/ics55_l3_scan.py \
  --coarse 0,8 --mid 0,8,15 --fine 0,8,31 \
  --out flow/characterization/ics55_l3
```

The script:

1. uses `syn/outputs/ics55/PLL_ILDCO.sp` (generated by the syn Makefile);
2. flattens the ics55 cell CDL with `flow/macro/ics55_h7cr/flatten_cdl.py`;
3. converts flattened `M` devices to `X` instances of the foundry
   `nm1p2_svt_lp`/`pm1p2_svt_lp` subcircuits;
4. uses the vendor BSIM4.5 model deck from
   `/grid/ics55/libs.tech/spice/foundry/ngspice`;
5. runs a 5 ns ngspice transient without `uic`;
6. parses the rawfile and writes `dco_tuning_l3.csv` / `dco_l3.json`.

## Data

```text
points = 18
coarse = {0, 8}
mid    = {0, 8, 15}
fine   = {0, 8, 31}
range  = 919.12 .. 1899.08 MHz
```

The 18 measured points are monotonic in both coarse and fine directions
within this sparse grid.  `coarse=15` was not included because the 5 ns
transient did not converge within the batch timeout; that is a runtime/settling
limitation, not a claim that the code is invalid.

## Status

```text
L3 transistor netlist:   working in ngspice
L3 PEX:                  not started
L3 PVT:                  not started
dense code grid:         not started
```

This is a sparse, pre-PEX L3 baseline.  It is not a jitter, PVT or production
signoff.

Generated netlists, model symlinks, rawfiles and logs are ignored; only the
README, CSV and JSON are tracked.
