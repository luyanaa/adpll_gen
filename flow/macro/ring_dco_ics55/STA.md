# Ring DCO macro timing

`sta.rpt` is an OpenSTA interface-timing report at nominal ics55 H7CR
TT/1.2 V/25 C.  COARSE/MID/FINE are treated as quasi-static asynchronous
controls and OUT/MID_OUT as free-running ring outputs; the report therefore
covers only the SS-BBPD/REF interface.  It is **not** an oscillator timing,
frequency, jitter or PVT signoff.
